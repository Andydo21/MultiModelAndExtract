Hierarchical Evidence Pods — pilot results

50 pilot questions, production main flow, text-only input to Qwen2.5-VL-7B (zero-shot). All data are read from the stored logs in research_evaluation_20261030/.

E1 on five table questions with cell-aware grids (gold and retrieved evidence). A: flat text, B: JSON, C: Markdown table, D: C + breadcrumb, E: full Evidence Pods (production renderer).

Labels (rubric in RUBRIC_DANH_GIA.md): correct = every requested part right; partial = one detail missing or one claim wrong; wrong; no_answer = model declined. Labels were assigned in an LLM-assisted pass and reviewed by the first author.

Evidence colours: green = the cited source is a gold region; red = it is not.

Reruns: P047–P050 were rerun after a temporary server outage, P007 after the output-language check that rejected its first answer was removed. The first-run rows are kept in mainflow_20261030/answers_images_off.before_rerun_20261031.jsonl.

Missing logs: the raw model output of P007's rejected first answer was not stored (raw outputs are stored for every later run); prompts of the main flow are rebuilt by the production code and are not stored per question. Ablation logs in runs/ contain full prompts.
